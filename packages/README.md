# Package metadata

Gentoo Portage is the system package manager. This directory is reserved for CarsonForge-specific package definitions, overlays, and provenance notes; it is not a separate package manager.

For each CarsonForge-maintained package or overlay, record the upstream project, exact version, source URL, checksum/signature status, license, patches, build instructions, dependencies, and any local USE-flag requirements. Prefer Portage ebuilds and existing Gentoo packages instead of duplicating upstream package definitions without a clear reason.
